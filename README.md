# Sideline

A chess app where you play against an AI coach who thinks aloud, hints at the right moments and gives feedback on your ideas. See [the product spec](./Sideline%20—%20Product%20Spec.md).

## Run

```
npm install
npm run dev          # http://localhost:5173
npm run dev:phone    # also serves on your Wi-Fi, open the "Network" URL on your phone
npm run build        # static site in dist/
```
